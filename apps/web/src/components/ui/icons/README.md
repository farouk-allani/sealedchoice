# Functional icons

A selected subset of [Remix Icon](https://github.com/Remix-Design/RemixIcon), on its original 24px grid. Domain and status icons use the filled family; arrows, checks, close and other simple action symbols use the corresponding family variants. These are interface controls, not brand artwork.

`paths.json` contains unmodified SVG path data. `sources.json` records each upstream SVG and its SHA-256 digest. The upstream license is retained in `LICENSE.txt`. Icons are rendered inline, without a font, package dependency or network request.
