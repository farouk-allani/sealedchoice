# Typography trial assets

These Latin-subset WOFF2 files are self-hosted by `next/font/local` for `/components`. No additional font service is contacted by visitors. Public Sans is the initial review choice; Barlow and the existing Inter pairing remain selectable. This is a comparison, not a typography migration of the landing page.

- [Public Sans](https://github.com/uswds/public-sans): variable upright weights 400 to 700. A neutral interface family developed by the United States Web Design System.
- [Barlow](https://github.com/jpt/barlow): upright weights 400, 500, 600 and 700. A grotesk family influenced by transportation and signage.
- [IBM Plex Mono](https://github.com/IBM/plex): upright weights 400 and 500. Used for technical references in both new options. Prices, scores and step numbers use the selected sans family with tabular numerals where appropriate.

Each family's directory includes its SIL Open Font License. `sources.json` records original download URLs, weights, byte sizes and SHA-256 digests. Files were retrieved from Google Fonts on 2026-11-06. The original Inter and JetBrains Mono configuration remains in the root layout.
