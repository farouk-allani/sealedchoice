## Start with the record

The current demonstration contains three completed tenders on `tenders-v1.sealedchoice.testnet`. The first awards the highest-ranked eligible bid. The second records a committee decision to select a lower-ranked bid with a written reason. The third records ten manipulation attempts and their outcomes.

This is a testnet prototype. tUSDC is a test token. The demo is a record of completed tenders, rather than a continuously open bidding competition. See [demo evidence](./evidence.md) for the transactions and [security and limits](./security.md) for the retained operator keys and trust assumptions.

## The process

1. **Publish:** the buyer fixes the rubric, deadline, committee, bond and evaluator reference when creating the tender.
2. **Seal:** suppliers encrypt bids in their browsers to the tender's public key. The chain receives ciphertext.
3. **Evaluate:** after the deadline, the contract freezes the bid set and requests the pinned evaluator in an OutLayer TEE. Code handles eligibility, prices, totals and ranking. Models assess the text criteria.
4. **Decide and pay:** a human committee makes the award. The winner accepts, and the contract transfers the award from escrow.
